How a paid call works

1 · 402Request the route; server replies with payment requirements
→
2 · SignClient signs a USDC authorization for $0.003
→
3 · SettleFacilitator verifies & settles on Base
→
4 · 200Response body carries the artifact + receipt header

Quickstart (agent side)

import { wrapFetchWithPayment, createSigner } from "x402-fetch";

const signer = await createSigner("base-sepolia", process.env.PRIVATE_KEY!);
const payFetch = wrapFetchWithPayment(fetch, signer);

const res = await payFetch(
  "http://localhost:4021/search?lat=41.3851&lon=2.1734&radius=2"
);
const activities = await res.json(); // purchased artifact, in-response
